M.B. SMART ACTION CENTER — Workflow Fix Audit
Baseline: Office-Work-main_Final_Stage20 candidate project
Changed file: index.html only

Changes:
1. M.B. Smart Action Center's Work button now calls sacOpenWorkEntry().
2. Bill button now calls sacOpenBillEntry().
3. Both actions require a valid latest M.B. issue/assignment to a JE present in je_records and currently held by that JE.
4. Work action closes the Smart Action Center and opens the existing Work List modal with JE and M.B. preselected. If an active work record exists for that M.B., the existing record is loaded in edit mode; otherwise a new work form opens with the selected M.B./JE prefilled.
5. Bill action blocks if assignment is missing or if no work name is recorded for the selected M.B. If valid, it closes the Smart Action Center, opens the existing Bill Register modal and existing bill wizard, and prefills JE, M.B., contractor, and work name.
6. Existing storage keys, saved records, calculations, wizard, work/bill save/edit/delete functions, and other modules were not rewritten.

Tests performed:

- Static checks: action wiring, guard messages, prefill logic, existing work/bill handlers, and no data mutation in the new helper passed.
- Mock behavior tests (4): missing assignment blocks Work; missing assignment blocks Bill; valid assignment opens Work with JE/M.B. prefilled; valid assignment + work opens Bill wizard with JE/M.B./work/contractor prefilled. All passed.
- ZIP integrity checked after packaging.
